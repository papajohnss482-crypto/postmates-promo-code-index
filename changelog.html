Changelog

Additions, removals, and corrections for every dataset version. A code that leaves the table does not disappear from history, it moves here with its removal date.

Site expansion, October 21, 2026

Pages added, data unchanged. The dataset itself stays at version 1.0. What changed is the site around it.

  • FAQ page added, with FAQ schema, covering user types, check dates, expiry labels, and why a listed code can fail on an account.
  • How to use page added, with step by step account and checkout instructions and the common failure checks.
  • About page added, covering independence, correction policy, and how to report an error.
  • Site navigation, footer links, and sitemap extended to all six pages.

Version 1.0, October 20, 2026

Dataset launched. Snapshot of the source record as published on October 17, 2026.

  • 9 community-reported code records added: DAYOFF, postmates-zdzi8958go, CC5OFF, VEGASFOODIE20, FINALKICK, eats-q1zgtnn8i6, FREEBIEFRIDAY10, LADELIVERYRUN, SPOOKY10. All checked October 2, 2026, dates preserved as recorded.
  • 3 verified in-app program records added: Uber One (checked Oct 2, trial re-verified Oct 13), $12 Meal Deals (verified Oct 13), Refer a friend (checked Oct 2).
  • CSV and JSON distributions published alongside the HTML table.

Source record events reflected in this snapshot

  • October 13, 2026: In-app offers re-verified by the source publication. Meal Deals and the Uber One trial confirmed live and unchanged since October 2.
  • October 3, 2026: A targeted in-app offer, $10 off the first 2 delivery orders of $20 or more for new and eligible users, expired and moved to the source publication's Recently Expired section. It was account targeted, not a public code, so it never entered this dataset as a code record. It is logged here as an example of the expiry policy working as intended: expired means recorded as expired, not quietly extended.
  • October 2, 2026: Community code check cycle completed by the source publication, 9 codes checked. SPOOKY10 added in this cycle, $10 off $25 or more, reported valid until November 1, 2026.

Postmates Promo Code Index is an independent open dataset, not affiliated with Postmates or Uber.
