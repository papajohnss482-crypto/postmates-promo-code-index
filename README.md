# Postmates Promo Code Index

An open, dated dataset of Postmates promo codes, tracked with honest source labels.

## Purpose (unique to this site)
Data and research. This site exists so bloggers, deal researchers, and users can see the current code list as structured data, download it, and cite it. It is not a copy of any other site.

## Contents
- index.html: live table of current codes (status, discount, minimum order, user type, last checked, source type)
- data/codes.csv and data/codes.json: the same dataset in machine readable form, versioned by date
- methodology.html: how codes are collected, how verification works, why listing board expiry countdowns are not real deadlines
- changelog.html: codes added and codes delisted, by date. Delisted codes are dropped, never held.

## Data rules
- Every code carries a genuine last checked date. Dates are never relabeled as current.
- Expiry is always stated as per community reports (unverified) unless verified in-app.
- Verified in-app is used only for offers evidenced by real app screenshots.
- Full guide and current verified list: https://postmatescoupons.us/ (source site, linked as a resource in Methodology)

## Platform target
GitHub Pages. Design: clean data table layout, light theme, no shared template with the other stack sites.
