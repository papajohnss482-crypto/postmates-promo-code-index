About this dataset

An independent open dataset of Postmates promo codes and in-app programs, published as versioned snapshots with the dates attached.

What it is

This site publishes a structured record of Postmates codes: the code, the offer, the minimum order, who it is for, where it applies, the date it was last checked, and the expiry as reported. The same data is downloadable as CSV and JSON from the dataset page, so researchers, bloggers, and deal trackers can cite it without copying undated lists.

Version 1.0, published October 20, 2026, is a snapshot of the source record as published on October 17, 2026. Between snapshots, the live list maintained by the source publication is the newer record. When the two differ, believe the live list and treat this dataset as the dated snapshot it declares itself to be.

What it is not

  • It is not affiliated with Postmates or Uber, and it is not an official Postmates page.
  • It is not a checkout tester. A community-reported code means users reported it working. It does not mean the code was tested at checkout, and it does not guarantee the code is assigned to your account.
  • It is not a fresh list. Check dates are genuine and are never edited forward. If a date looks old, that is the honest state of the record.

How corrections work

Every change to the dataset is recorded on the changelog page: additions, removals, and corrections, all with dates. When a code is delisted at its source, the next dataset version removes it from the table and the removal stays visible in the changelog. Delisted codes are dropped, never held with a new expiry. The full rules are on the methodology page.

Report an error

If a code in the table is wrong, or a date is misprinted, open an issue on the project repository at github.com/papajohnss482-crypto/postmates-promo-code-index with the code, what you saw, and the date. Corrections go into the changelog with credit to the report, not silently into the table.
