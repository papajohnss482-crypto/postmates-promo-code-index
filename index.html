Postmates Promo Code Index, October 2026 Snapshot

Dataset version 1.0, published October 20, 2026. This is a structured snapshot of the Postmates code record as published by the source publication on October 17, 2026. It exists so researchers, bloggers, and deal trackers can cite code data with its dates attached, instead of copying undated lists.

Read the dates before you use a code. Community codes below were last checked on October 2, 2026, and that date is shown on every record on purpose. An older check date is honest data, not a defect we hide. Codes are targeted by account, so a listed code can still fail on your account. Expiry is per community reports (unverified) unless a date is printed from the source record.

How to cite this dataset

Postmates Promo Code Index, version 1.0 (October 20, 2026). Snapshot of the record published October 17, 2026 by the source publication, Postmates Coupons, which maintains the live list with per code check dates between dataset snapshots. If you republish a code from this dataset, keep its last checked date and its source label with it. A code stripped of its date is how stale lists are born. This dataset is shared under CC BY 4.0.

What this dataset will never do

  • Relabel an old check date as a new one to look fresh.
  • Keep a delisted code in the table with a quietly extended expiry.
  • Call a community-reported code tested or verified.
  • Add codes from dumped lists with no check date at all.

The rules behind these promises are written out on the methodology page, and every change to the dataset is recorded on the changelog page.

Postmates Promo Code Index is an independent open dataset, not affiliated with Postmates or Uber. Confirm every code in the app under Account, Promotions, Add promo code before ordering.
