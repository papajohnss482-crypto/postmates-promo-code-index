How to use a Postmates promo code

The order matters: add the code to your account first, confirm the discount at checkout second, and only then place the order. A code cannot be added after the order is placed.

Step 1: Add the code to your account

  1. Open the Postmates app and tap Account.
  2. Tap Promotions, then Add promo code.
  3. Enter the code exactly as written, including case, and tap Apply.
  4. A valid code appears under Active Promotions, with its expiry date and the country where it can be used.

Adding a code does not order anything. It only attaches the code to your account, so you can check whether it is valid before you build an order.

Step 2: Check the terms before you order

  • Minimum order. Most codes in this dataset need $25, or $15 per order for CC5OFF, calculated before tax, tips, and fees.
  • User type. New-customer codes only work on new accounts. DAYOFF, eats-q1zgtnn8i6, FREEBIEFRIDAY10, and LADELIVERYRUN are listed for all users.
  • City. FINALKICK works only in Las Vegas. LADELIVERYRUN works only in Los Angeles. VEGASFOODIE20 is limited to select stores.
  • One code per order. A second code cannot be stacked on the same order. Restaurant offer tags can still apply on top, but not a second code.

Step 3: Confirm the discount at checkout

  1. Add items to the cart and open it.
  2. Tap Add promo and select the code, if it is not already applied.
  3. Check the order summary. The discount should show before you tap Place order.
  4. If the discount is missing, stop and check the terms in Step 2 before ordering. Ordering first and asking later does not work.

Why a code fails, and what to check first

  • Spelling and case. Codes are case sensitive. Copy the code from the dataset table rather than typing it from memory.
  • Minimum not met. The minimum counts the item subtotal only, not delivery fees, service fees, tax, or tips.
  • Wrong account type. A new-customer code on an existing account will not apply, even if the code itself is live.
  • Wrong city or store. City codes and select-store codes only apply where they are scoped.
  • Already redeemed. Most codes are single-use per account. A code already used on your account will not apply again.
  • Auto-apply tools. Browser extensions that auto-fill codes can silently override the code you entered. If a good code will not apply, disable the extension and retry.

When a membership beats a code

Uber One on Postmates costs $9.99 per month, with a 4 week free trial on some accounts, and gives $0 delivery fees over a minimum subtotal plus up to 10 percent off delivery and pickup orders. Those figures are from the in-app check on October 2, 2026, with the trial re-verified October 13, 2026. For anyone ordering 3 or more times a month, the waived delivery fees usually beat a one-off code over the month. For an occasional order, a code like DAYOFF is the better pick. Do the math on your own order frequency before choosing.
