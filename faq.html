Frequently asked questions

Straight answers about this dataset, the codes in it, and the dates attached to them. If a question is about using a code step by step, see the how to use page.

What is the Postmates Promo Code Index?

It is an open, versioned dataset of Postmates promo codes and in-app programs. Version 1.0 is a snapshot of the source record as published on October 17, 2026. It exists so researchers, bloggers, and deal trackers can cite code data with its dates attached, instead of copying undated lists. The data is also downloadable as CSV and JSON from the dataset page.

What does community-reported mean?

It means users reported the code working, and the code was collected from public deal communities. It does not mean the code was tested at checkout, and it does not guarantee the code is assigned to your account. Postmates codes are targeted, so a code that worked for one account can fail on another.

Why did a listed code fail on my account?

The usual reasons are targeting, user type, minimums, and geography. New-customer codes only work on new accounts. Several codes need a minimum order, usually $25, calculated before tax, tips, and fees. FINALKICK works only in Las Vegas and LADELIVERYRUN only in Los Angeles. A code can also be single-use per account, already redeemed, or expired.

Which codes in this dataset work for existing users?

DAYOFF, eats-q1zgtnn8i6, FREEBIEFRIDAY10, and LADELIVERYRUN are listed for all users. The other five codes, postmates-zdzi8958go, CC5OFF, VEGASFOODIE20, FINALKICK, and SPOOKY10, are listed for new customers or new accounts.

Why do you show old check dates instead of today's date?

Because the check date is the honest date of the check. The community codes in version 1.0 were checked on October 2, 2026. Editing that date forward to look fresh would mislead readers and other sites that cite the data. An older check date is honest data, not a defect we hide. The next snapshot follows the source publication's next check cycle, and every change is recorded on the changelog page.

What does per community reports (unverified) mean for expiry?

It means the expiry comes from listing sources, not from Postmates, and tracking shows those listing countdowns being extended while the offer itself does not change. Treat such dates as reports, not deadlines. Where the source record prints a specific expiry date, the dataset reproduces it and says so, for example the October 25, 2026 date on eats-q1zgtnn8i6 and the November 1, 2026 date on SPOOKY10.

How do I use a code from this dataset?

Open the Postmates app, go to Account, then Promotions, then Add promo code, and enter the code exactly. Valid codes appear under Active Promotions with their expiry and country. At checkout, open the cart, tap Add promo, and confirm the discount in the order summary before placing the order. Only one code works per order. The full steps are on the how to use page.

Is this site affiliated with Postmates or Uber?

No. This is an independent open dataset, not affiliated with Postmates or Uber. Confirm every code in the app under Account, Promotions, Add promo code before ordering.

Can I cite or republish this dataset?

Yes. Cite it as Postmates Promo Code Index, version 1.0 (October 20, 2026). If you republish a code, keep its last checked date and its source label with it. A code stripped of its date is how stale lists are born. The CSV and JSON downloads are on the dataset page.
